# Recursos compartidos
Repositorio de activos multimedia y documentos de soporte a usar en otros proyectos

Repositorio de activos multimedia y documentos de soporte utilizados en la línea de tiempo interactiva (Timeline.js) y el informe-ensayo sobre la historia del LaserDisc.

Los archivos alojados en este repositorio se sirven directamente a través de las URLs *Raw* de GitHub (`https://raw.heipry.com/...`) para garantizar su visualización pública sin bloqueos de origen (*hotlinking*).****
